## Compiling and Using the Common Wrapper
    The common_wrapper directory contains the wrapper files provided for the CS509 lab. These files are intended to provide a common interface for compiling and running assignments.
    To compile an assignment, include the wrapper file along with the source files of that assignment.
    g++ -std=c++17 driver/main.cpp src/*.cpp ../common_wrapper/wrapper.cpp -o driver    
    After compilation, execute the generated program using:
    driver.exe
    The same wrapper can be reused across different assignments without making changes to its implementation.

## Observations

- Both Simple GEMM and Blocked GEMM produced the correct output for all test cases.
- For small matrices, the execution time is very low, and there is little difference between the two algorithms.
- As the matrix size increases, Blocked GEMM performs better than Simple GEMM because it improves cache utilization.
- The performance improvement becomes more noticeable for larger matrices, especially for the 200 × 200 × 200 and 500 × 500 × 500 test cases.
- Both algorithms have the same theoretical time complexity, but Blocked GEMM achieves better practical performance on large matrices.

## Test Files, Outputs, and Runtime Measurement

The following conventions are followed in this repository:

* Test input files are placed in the tests folder of each assignment.
* Output files generated by the program are stored in the outputs folder.
* Sample test cases are provided to check whether the program is working correctly.
* The execution time of the program is measured using the C++ <chrono> library.
* The same set of input files is used while comparing different implementations so that the performance comparison is fair.
* A common folder and file naming style is followed across all assignments to keep the repository organized and easy to navigate.
